## How to run
```bash
python -m venv .venv && .venv/Scripts/activate      # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt                      # Python >= 3.12
python run_all.py --clean --tests                    # ~1 min; rebuilds data/, results/, figures/, models/
streamlit run app.py
bash scripts/check_fresh_env.sh                      # full from-scratch verification (~5 min)
pip install -r requirements-dev.txt && python scripts/capture_screenshots.py   # app screenshots
```

## Key files
- `src/oncolens/`: config, data, models, metrics, selection, calibration, threshold, explain, errors,
  style, plots_eda, plots_model, plots_shap, app_support, io_utils.
- `scripts/01..08_*.py`: pipeline steps, run in order by `run_all.py`.
- `results/`: every metric (CSV/JSON/MD). `results/summary_tables.md` feeds the README.
- `figures/` + `figures/CAPTIONS.md`; `docs/screenshots/`.
- `DECISIONS.md`: every judgment call and why.
- Gotchas: in Git Bash on this machine, heredocs containing backslashes or quotes get mangled, so use the
  editor tools for Python edits. On Windows, pass `encoding="utf-8"` to `Path.write_text`.
